# 🎁 Сколько скинуться коллеге на ДР

Одностраничный калькулятор подарка коллеге по универсальной формуле:

```
(X / 500 + Y / 100) × K × N
```

* **X** — твоя зарплата
* **Y** — общая сумма, которую дарили тебе коллеги на твой ДР
* **K** — коэффициент рабочей близости: `0,5` не в твоём отделе · `1` твой отдел, другая функция · `1,5` твоя функция · `2` руководитель или подчинённый
* **N** — коэффициент личной близости: `0,5` реже раза в неделю · `1` почти каждый день · `1,5` вместе выпивали · `2` ходили друг к другу в гости

## Что умеет

* живой пересчёт при вводе сумм и клике по коэффициентам;
* округление результата вверх — точно / до 100 ₽ / до 500 ₽;
* разбор расчёта с подставленными числами;
* ссылка с параметрами (`?x=80000&y=3000&k=1.5&n=1`) — можно скинуть коллегам точный расчёт;
* запоминает последние введённые данные в `localStorage`;
* кнопки «Поделиться» (нативный шаринг на телефоне) и «Скопировать сумму»;
* адаптив под телефон, тёмная тема, анимации с уважением к `prefers-reduced-motion`.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка страницы |
| `styles.css` | вся вёрстка и оформление |
| `app.js` | логика расчёта и интерактив |
| `publish.ps1` | публикация на GitHub Pages одной командой |

Никаких сборок, зависимостей и npm — чистые HTML/CSS/JS, поэтому GitHub Pages подходит идеально.

## Локальный запуск

Просто открой `index.html` в браузере. Если хочется «как на сервере»:

```powershell
python -m http.server 8080
# затем http://localhost:8080
```

## Публикация на GitHub Pages

### Вариант 1: скриптом (нужен GitHub CLI)

```powershell
gh auth login          # один раз
cd dr-gift
.\publish.ps1 -Repo dr-gift
```

Скрипт создаст публичный репозиторий, запушит файлы и включит GitHub Pages.

### Вариант 2: руками через сайт GitHub

1. Создай новый публичный репозиторий, например `dr-gift`.
2. Загрузи в него `index.html`, `styles.css`, `app.js` (кнопка **Add file → Upload files**).
3. **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main`, папка `/ (root)` → **Save**.
4. Через минуту сайт будет доступен по адресу `https://<твой-логин>.github.io/dr-gift/`.

> Хочешь короткий адрес вида `https://<логин>.github.io/` — назови репозиторий `<логин>.github.io`.

### Обновление сайта

Отредактировал файлы → закоммитил → запушил в `main`. Pages пересобирается сам за ~30–60 секунд.
